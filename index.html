Ссылка для энергетика: —

  1. Супер‑администратор заполняет все данные и нажимает «Создать организацию».
  2. Формируется ссылка, которую супер‑администратор отправляет энергетику.
  3. Энергетик открывает ссылку в приложении, и его ID приписывается этой организации.
  4. В файле access.json в разделе organizations добавляется организация и первый пользователь с id (из пункта 3), fullName (Фамилия Имя Отчество, которые ввел супер‑администратор в пункте 1) и ролью «Энергетик».
  5. В файле data/organizations.json в разделе organizations добавляется название новой организации.
  6. В data/organizations добавляется папка с названием данной организации и всеми нужными файлами.
