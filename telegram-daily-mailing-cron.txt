# Рассылки Alltrack без дополнительных настроек сервера.
# Достаточно вызывать URL (например, через UptimeRobot / cron-job.org / GitHub Actions):
# https://<ваш-домен>/js/alltrack/save.php?action=run-scheduled-mailings
#
# Важно:
# - Время проверяется строго по Москве (Europe/Moscow).
# - Вызов делайте 1 раз в минуту, чтобы не пропустить нужную минуту.
# - Рассылки уйдут только в точно заданную минуту из настроек.
#
# Пример для внешнего планировщика (каждую минуту):
# GET https://<ваш-домен>/js/alltrack/save.php?action=run-scheduled-mailings
#
# Если нужен локальный cron на сервере, можно оставить этот вариант:
# * * * * * cd /var/www/www-root/data/www/bimmax.pro/js/alltrack && /usr/bin/php save.php --run-scheduled-mailings >> /var/www/www-root/data/www/bimmax.pro/js/alltrack/telegram-scheduled-mailings-cron.log 2>&1
