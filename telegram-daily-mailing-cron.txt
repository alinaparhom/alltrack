# Рассылки Alltrack без cron и без дополнительных настроек сервера.
# Планировщик можно запустить один раз, дальше он работает сам каждую минуту в фоне.
#
# Запуск фонового планировщика (один раз):
# php telegram-scheduler.php --start-daemon
#
# Проверка статуса:
# php telegram-scheduler.php --status
# или
# https://<ваш-домен>/js/alltrack/telegram-scheduler.php?action=status
#
# Запуск из браузера (один раз):
# https://<ваш-домен>/js/alltrack/telegram-scheduler.php?action=start-daemon
#
# Что запускается каждую минуту:
# - save.php --run-scheduled-mailings
# - рассылка "Ответы на перемещения" строго в заданную минуту по Москве (Europe/Moscow)
# - рассылка "Таблица перемещений" выбранным пользователям по расписанию из настроек организации
