# Рассылки Alltrack без дополнительных настроек сервера.
# Вызывайте один файл раз в минуту (через UptimeRobot / cron-job.org / GitHub Actions):
# https://<ваш-домен>/js/alltrack/telegram-scheduler.php
#
# Важно:
# - Время проверяется строго по Москве (Europe/Moscow).
# - Вызов должен быть каждую минуту.
# - Рассылки уйдут только в точно заданную минуту из настроек.
#
# Пример для внешнего планировщика (каждую минуту):
# GET https://<ваш-домен>/js/alltrack/telegram-scheduler.php
#
# Локальный cron на сервере (каждую минуту):
# * * * * * cd /var/www/www-root/data/www/bimmax.pro/js/alltrack && /usr/bin/php telegram-scheduler.php >> /var/www/www-root/data/www/bimmax.pro/js/alltrack/telegram-scheduled-mailings-cron.log 2>&1
